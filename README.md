## Executar
Abra o arquivo `index.html` no navegador ou publique o repositório com GitHub Pages.

## Antes de publicar para o cliente
- Confirmar o telefone: o material enviado mostra (11) 97989-1775, enquanto a ficha do Google enviada anteriormente mostra (11) 92104-1395.
- Confirmar se a promoção de 2 Sacodão por R$ 50,99 ainda está vigente e suas condições.
- Substituir as fotos demonstrativas por fotos oficiais da hamburgueria. As imagens atuais são ilustrativas.
- Confirmar o cardápio, preços e horários diretamente com o estabelecimento.
